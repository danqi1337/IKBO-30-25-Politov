# Эмулятор оболочки UNIX (вариант 21)

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
(tkinter). Реализован на Python 3.10+, внешних зависимостей нет.
Заголовок окна формируется из реальных данных ОС:
`Эмулятор - [username@hostname]`.

Состояние проекта: **этап 2 (конфигурация)**.

## 2. Функции и настройки

### Парсер

Строка делится на слова по пробелам. Поддерживаются:

- двойные кавычки `"my dir"` (внутри работает `\"` и `\\`);
- одинарные кавычки `'a b'` (всё внутри сохраняется как есть);
- пустой аргумент `""`;
- экранирование `a\ b`.

Символ `#` в начале слова начинает комментарий до конца строки.
Ошибки разбора (незакрытая кавычка, `\` в конце строки) выводятся
как `parse error: ...`.

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | путь к физическому расположению VFS (используется с этапа 3) |
| `--log PATH` | путь к CSV-журналу (по умолчанию `emulator_log.csv`) |
| `--script PATH` | путь к стартовому скрипту |
| `--headless` | консольный режим без окна (для автотестов и скриптов ОС) |

При запуске все параметры выводятся в окно (консоль). Ошибки чтения
скрипта и открытия журнала выводятся туда же как `Ошибка: ...`,
эмулятор продолжает работу (без скрипта или без журнала).

### Журнал (CSV)

Каждый вызов команды (в том числе ошибочный и неизвестный) пишется
в файл журнала. Столбцы: `timestamp` (дата и время, ISO 8601), `user`
(имя пользователя ОС), `command`, `arguments` (JSON-список), `status`
(`ok` / `error`). Заголовок пишется в новый файл, затем события
дописываются.

### Стартовый скрипт

Файл с командами эмулятора, по одной в строке. Пустые строки и
комментарии (`# ...`) пропускаются. При выполнении на экране
показываются и ввод (с приглашением), и вывод, как в диалоге.
Строка с ошибкой пропускается с сообщением
`[скрипт] ошибка в строке N, строка пропущена`. `exit` в скрипте
завершает работу эмулятора.

### Команды

| Команда | Описание |
|---------|----------|
| `ls [args...]` | заглушка: печатает имя и аргументы |
| `cd [dir]` | заглушка: печатает имя и аргументы |
| `exit` | завершает работу эмулятора |

Ошибки: `foo: command not found`, `cd: too many arguments`,
`exit: too many arguments`.

В окне работает история команд (стрелки вверх/вниз).

## 3. Сборка и тесты

Сборка не требуется. Нужны Python 3.10+ и tkinter
(в Debian/Ubuntu: `sudo apt install python3-tk`).

```sh
./run.sh --script tests/scripts/test_stage2.txt   # или make run ARGS=...
make test                                         # запуск тестов
```

В Windows вместо `run.sh` используйте `run.bat`.

Скрипты реальной ОС для проверки параметров (есть версии `.sh` и
`.bat`) лежат в `tests/os_scripts/`:

- `check_script_param` — параметр `--script`;
- `check_log_param` — параметр `--log`;
- `check_all_params` — все параметры вместе и `--help`.

Стартовые скрипты эмулятора лежат в `tests/scripts/`.

## 4. Примеры

```text
root@vm:~$ ls -l "my dir" 'a b' ""
ls: args=['-l', 'my dir', 'a b', '']
root@vm:~$ cd one two
cd: too many arguments
root@vm:~$ cd "unclosed
parse error: unterminated quote "
root@vm:~$ foo --bar
foo: command not found
```

Запуск со скриптом и журналом:

```sh
./run.sh --headless --log /tmp/log.csv --script tests/scripts/test_stage2.txt
```

```text
timestamp,user,command,arguments,status
2026-10-07T18:52:08,root,ls,[],ok
2026-10-07T18:52:08,root,foo,"[""--bar""]",error
```
